# Godot Project

空白 Godot 4.6 工程。已保留 agent harness（`.cursor/`、`AGENTS.md`、`Documents/DEVELOPMENT_WORKFLOW.md`）与美术素材（`assets/`、`art_source/`）。

## 快速开始

1. 用 Godot 4.6 打开本目录
2. 主场景：`scenes/main/main.tscn`
3. 轻量验收：`bash tools/run_light_verify.sh`
4. Web 部署：推送 `main` 或手动跑 Actions **Deploy Web**（见 [Documents/WEB_DEPLOY.md](Documents/WEB_DEPLOY.md)）
