# Feature：誓约与羁绊

> 状态：To-Be 定稿（未实现）  
> 验收方式：完全  
> 相邻：[economy_shop_merge.md](./economy_shop_merge.md)、[Content/unit_roster.md](../Content/unit_roster.md)

## 本文要写什么

冠军单位的**关键词**、多枚同关键词冠军触发的**誓约（羁绊）**加成，以及与军队构筑的关系。

## 本文不写什么

具体加成百分比、完整誓约平衡表、遗物与誓约的交叉数值（只定「可互动」）。

## 关键词

- 每个**冠军**至少带 1 个构筑关键词（可多标签，首批建议每兵种主标签 1 个）。
- 新兵/老兵可不显示关键词，或仅预告「冠军后获得」；以冠军为誓约计数来源。

### 首批关键词（中世纪奇幻包装）

| 关键词 | 构筑直觉 |
|--------|----------|
| 先锋 | 承伤、护甲、前线 |
| 围城 | 对建筑/精英/高血量目标、攻城器械感 |
| 蜂群 | 数量、死亡触发、复活节奏 |
| 游侠 | 暴击、侧翼、机动 |
| 近战 | 贴身输出与击退类协同 |
| 支援 | 治疗、军旗、光环增益 |
| 射术 | 远程火力与风筝 |

兵种 → 关键词映射见 [unit_roster.md](../Content/unit_roster.md)。可随 Phase 增减标签，但不另开「无限关键词库」脑暴。

## 誓约触发

- **计数域定案**：统计**本局军队名册**中所有冠军的关键词（含正在复活队列中的冠军；军队即名册，不另设「未部署」池）。
- 达到解锁阈值时点亮对应**誓约**，给予军队或符合标签单位的加成。
- 解锁档位（例如 2/4 冠军）由数值配置；功能上支持**至少两档**。
- 出售或永久移出军队导致掉解锁时，誓约降档或熄灭；仅阵亡进复活队列**不**掉计数。
- HUD 显示已点亮誓约与进度。

### Phase D 首批誓约（先做 3 条）

| 誓约 | 关键词 | 效果类型（功能） |
|------|--------|------------------|
| 铁壁誓约 | 先锋 | 全军或先锋单位减伤/护甲向 |
| 万骨誓约 | 蜂群 | 缩短复活或死亡触发向 |
| 劲弦誓约 | 射术 | 远程伤害/攻速向 |

其余关键词誓约随后续内容切片追加，不阻塞 D 验收。

```text
誓约定义
  → 关键词、解锁阈值列表、效果类型（属性光环 / 触发规则）
  → 作用范围（全军 / 仅带该关键词单位）
```

## 与玩家决策的关系

- 商店刷新与合兵的目标从「堆高单一单位」扩展为「凑冠军关键词」。
- 种类上限（约 6）迫使在深度合单一兵与广度点亮誓约之间取舍。

## 验收要点（完全 · 随 Phase）

- 冠军生成后关键词可见；达阈值点亮誓约且效果生效（Phase D）。
- 出售导致掉阈值时誓约正确熄灭或降档；复活中的冠军仍计数。
- runner 覆盖计数与解锁边界；L4 需誓约 HUD 证据。
