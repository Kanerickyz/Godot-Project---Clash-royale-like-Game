# Feature：小队刷怪 / Boss 回血 / 侧向撞飞 / 友方时停

> 状态：已实现（轻量加载通过；效果用户自验）  
> 验收方式：**轻量**（`bash tools/run_light_verify.sh`；效果用户自验）

## 玩家可观察变化

1. **续刷成小队**：一次续刷可在同一房间附近刷出多名敌人（小队伍），且随比赛进程小队人数倾向增多。
2. **Boss 可回血**：Boss 在脱战一段时间后缓慢回血（可配置）；冲撞/召唤等战斗行为会打断或重置脱战计时。
3. **撞飞带侧向力**：被冲撞时飞出轨迹相对冲撞方向有侧向偏移（抛物线仍在），不是纯直线甩开。
4. **友方被撞时停**：有我方单位被冲撞命中时，短暂全局时停（Hitstop）；同一次冲撞命中多名友方时**只触发一次**时停。

## 规则要点

### 小队刷怪
- 续刷时按「小队人数」采样：`squad_size` 随 `_match_elapsed` 从较小区间 lerp 到较大区间。
- 同一次小队成员落点彼此靠近（同房间或中心点附近小半径），形成一小波。
- 仍尊重 `max_alive_enemies`。

### Boss 回血
- Boss（敌方）也可走回血：脱战延迟后每秒回复；数值可进 `BossBehaviorConfig`。
- 造成/受到伤害、发动冲撞/召唤时视为在战，重置脱战计时。

### 侧向撞飞
- 在冲撞方向基础上叠加随机或交替的侧向分量（可配置侧向比例），再做现有抛物线 Tween。

### 时停
- 仅当被命中目标为**友方**时请求时停；`Engine.time_scale` 或自管 pause 均可，约 0.08–0.15s 真实时间后恢复。
- 同一次 Boss 冲撞结算窗口内，多友方命中只触发一次。

## 非目标（一句）

不改商店/地图生成主逻辑；不做长时间子弹时间。
