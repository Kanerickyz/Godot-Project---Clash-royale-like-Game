# Feature：城际跑商沙盒（最小双层）

> 状态：设计定稿；玩法已实现（轻量加载通过；效果用户自验）  
> 验收方式：**轻量**（`bash tools/run_light_verify.sh`；效果用户自验）  
> 切片合同：实现完成 + 加载通过；不自称 L3+

## 本文要写什么

可玩的最小双层沙盘：世界层多城节点与路线、城内招人与一种货买卖、路上概率遭遇进入现有小队自动战、死亡只按金币计分。

## 本文不写什么

攻城、势力外交、俘虏、多货种、背包容量、战斗中被抢货、永久跨局成长、同图 Boss 通关、点选编队微操、宝箱三选一、商店金币刷新货架、刷怪加速压迫（战斗层可用固定少量杂兵即可）。

## 相对旧原型

| 旧（As-Is 将被替换） | 新（本 Feature） |
| --- | --- |
| 单图程序化地牢为主循环 | 世界层城池节点为主循环 |
| 地图角落商店 + 宝箱招人 | 城内菜单招人 |
| 击败同图 Boss 即胜 | 无终局胜利；死了结算金币分 |

旧文档（小队游走、Boss、程序化地图刷怪等）保留作机制参考；**主循环以本 Feature 与愿景为准**。

## 玩家操作与胜负

| 项 | 规则 |
| --- | --- |
| 世界移动 | 在城节点与连接路线上移动（摇杆/WASD 或点选邻城；以实现可读为准） |
| 进城 | 抵达城节点可打开城内菜单（安全，无战斗） |
| 城内 | 招人（花钱入队）/ 买货 / 卖货 / 离开 |
| 遭遇 | 行军途中按概率进入战斗层；打完回世界层 |
| 战斗 | 只控队长；队友自动跟打；击杀掉落金币，队长踩到入账 |
| 本局结束 | 队长死亡（或无法再战） |
| 分数 | **仅金币**；持货作废不计入 |

## 世界层

- 至少 **2 座城** + 至少一条连接路线。
- 可从一城走到邻城而不强制遇敌（遭遇有概率）。
- 世界层 HUD 显示：金币、持货数量、当前所在/目标提示。

## 城内菜单

进城打开面板，首版只含：

1. **招人**：固定货架若干槽，标价可见；金币足够则可购入队（沿用现有单位定义资源）。
2. **买卖货**：显示本城对该货的买价与卖价；买扣金币加持货，卖扣持货加金币；金币不足或持货为 0 时对应按钮不可用。
3. **离开**：关菜单回世界层。

不做刷新货架、多页内政、伤兵营。

## 跑商（一种货）

- 货种：1 种（显示名可配置，如「粮食」）。
- 每城有买价、卖价（或统一本城单价用于买卖——二城价差须对玩家可见）。
- 玩家有持货数量（整数）；无背包容量上限（本切片）。
- 数值进 `resources/`（如世界/贸易配置），本文不定具体点数。

## 战斗层（复用）

- 进入遭遇时生成小型战斗场地与若干敌对单位；**不**刷 Boss、不刷宝箱商店建筑。
- 胜：清场或达成「可离开」条件后回世界层，保留队伍、金币、持货。
- 负：队长死 → 结算界面显示本局金币分；持货清零不展示为得分。
- 重新开始：重载本局（新一局）。

## 对象与属性大类

```text
城池
  → 显示名、世界坐标/节点位置
  → 该货买价、卖价
  → 招人货架候选（单位定义 + 标价）

贸易货物（一种）
  → 显示名
  → 玩家持有数量

世界行军
  → 当前城或路线进度
  → 遭遇概率（可配置）

经济
  → 金币（分数唯一来源）
  → 持货（失败作废）

单位（队长 / 队友 / 遭遇敌人）
  → 生命 / 攻击 / 移动 / 阵营（沿用现有）
```
