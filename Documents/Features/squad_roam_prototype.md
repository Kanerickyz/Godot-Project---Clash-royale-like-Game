# Feature：小队游走招募原型

> 状态：原型已实现（轻量加载通过；效果用户自验）  
> 验收方式：**轻量**（`bash tools/run_light_verify.sh`；效果用户自验）  
> 切片合同：实现完成 + 加载通过；不自称 L3+

## 本文要写什么

可玩的最小原型：队长控制、自动跟打小队、遭遇掉金币、商店固定货架招人、有血量宝箱三选一、同图 Boss 胜负。

## 本文不写什么

点选编队、打赢直接招募、永久成长、刷新货架、多货币、多 Boss/多章节、完整单位花名册、技能树、词条 build。程序化地图与续刷见 [roguelike_map_spawn.md](./roguelike_map_spawn.md)。

## 玩家操作与胜负

| 项 | 规则 |
| --- | --- |
| 移动 | 屏幕底部居中透明虚拟摇杆（兼 WASD/方向键）控制队长 |
| 战斗 | 队友（及队长）自动攻击；伤害飘字；简单移动/静止/攻击/死亡 Tween |
| 回血 | 脱离战斗约 5 秒后开始自动回血（我方） |
| 金币 | 击杀敌人掉落地上金币，**队长踩到才拾取** |
| 商店 | 队长在商店附近**不移动满 3 秒**自动打开固定货架；花金币购买未售罄角色入队 |
| 宝箱 | 停留在宝箱附近即自动战斗砸箱；摧毁后弹出三选一，选一人入队 |
| 胜利 | 击败本局唯一 Boss |
| 失败 | 队长死亡（队伍无法再战） |

## 主循环

遭遇胜利 → 获得金币 → 商店买人 / 砸箱三选一 → 队伍变强 → 择机打同图 Boss。

## 商店

- 地图上有一处商店建筑。
- **固定货架**：开局确定若干可购角色与标价；买走后该槽售罄。
- **打开方式**：队长在交互范围内静止约 3 秒自动打开（移动端友好，无需额外按键）。
- 相对安全：不要求先打架才能浏览货架。

## 宝箱

- 地图上放置若干宝箱；各有生命值。
- **靠近即自动砸**：队伍在宝箱附近自动攻击；血量归零后打开。
- 打开后从三个候选角色中选一加入；免费。
- 定位：冒险向（相对商店更不安全/更省钱）。

## 移动端

- 目标比例：iPhone 14 Pro 逻辑分辨率约 **393×852** 竖屏。
- 画面底部居中放大透明虚拟摇杆。
- 相机略远于最初原型，仍服务竖屏可读（见地图 Feature）。
- UI 使用 Noto Sans + DroidSansFallback，覆盖英文 / 中文 / 数字。
- 商店靠停留打开；宝箱靠停留自动战斗；商店/宝箱 UI 按钮仍可触控。

## 对象与属性大类

数值具体点数由 `resources/` 填空，本文只定功能骨架。

