# Feature：小队游走招募原型

> 状态：原型已实现（轻量加载通过；效果用户自验）  
> 验收方式：**轻量**（`bash tools/run_light_verify.sh`；效果用户自验）  
> 切片合同：实现完成 + 加载通过；不自称 L3+

## 本文要写什么

可玩的最小原型：队长控制、自动跟打小队、遭遇掉金币、商店固定货架招人、有血量宝箱三选一、同图 Boss 胜负。

## 本文不写什么

点选编队、打赢直接招募、大世界生成、永久成长、刷新货架、多货币、多 Boss/多章节、完整单位花名册、技能树、词条 build。

## 玩家操作与胜负

| 项 | 规则 |
| --- | --- |
| 移动 | 玩家控制队长在地图上移动 |
| 战斗 | 队友（及队长）自动攻击进入射程的敌对目标（敌人、宝箱、Boss） |
| 商店 | 靠近商店并交互，打开固定货架；花金币购买未售罄角色入队 |
| 宝箱 | 队伍自动攻击有血量的宝箱；摧毁后弹出三选一，选一人入队 |
| 胜利 | 击败本局唯一 Boss |
| 失败 | 队长死亡（队伍无法再战） |

## 主循环

遭遇胜利 → 获得金币 → 商店买人 / 砸箱三选一 → 队伍变强 → 择机打同图 Boss。

## 商店

- 地图上有一处商店建筑。
- **固定货架**：开局确定若干可购角色与标价；买走后该槽售罄。
- 相对安全：不要求先打架才能浏览货架（需在交互范围内）。

## 宝箱

- 地图上放置若干宝箱；各有生命值。
- 队伍自动攻击；血量归零后打开。
- 打开后从三个候选角色中选一加入；免费。
- 定位：冒险向（相对商店更不安全/更省钱）。

## 对象与属性大类

数值具体点数由 `resources/` 填空，本文只定功能骨架。

```text
单位（队长 / 队友 / 敌人 / Boss）
  → 生命
  → 攻击（伤害、攻击间隔、射程）
  → 移动（移速；队友跟随队长）
  → 阵营（我方 / 敌对）

  → 角色定义引用、标价、是否售罄

宝箱
  → 生命
  → 打开后三名候选角色
```
