# Feature：一局流程、楼层与胜负

> 状态：To-Be 定稿（未实现）  
> 验收方式：完全  
> 相邻：[combat_threat_revive.md](./combat_threat_revive.md)、[economy_shop_merge.md](./economy_shop_merge.md)、[delivery_phases.md](./delivery_phases.md)

## 本文要写什么

一局（run）如何开、如何按楼层推进、层间切商店、何时胜利/失败，以及与永久成长的交接边界。

## 本文不写什么

层内战斗细则、商店定价与合兵规则、誓约公式、遗物词条表、具体楼层数量与 Boss 血量（留给数值）。

## 结构单位

- **一局**：从开局到胜利或失败的完整流程。
- **楼层**：程序生成的地城层；玩家在层内漫游战斗。
- **层间**：离开本层后进入商店界面（招兵 / 遗物），确认后进入下一层。
- **终局层**：最后一层含高潮 Boss（血肉狂欢式终局对抗的中世纪奇幻包装）；击败即通关。

地城类型（地下墓穴、水道、竞技场、圣所等）作为楼层主题皮肤与刷怪倾向，随 Phase 解锁；首批可只做一种布局。

## 开局

1. 选择可玩指挥官（独特被动/主动；首版可先做一个默认角色）。
2. 进入第 1 层；可带起始小股军队或空编（由数值定）。
3. 开局天赋（Perk）归 Phase G 可选，非开局最小集。

## 层内目标节奏

| 要素 | 玩家意义 |
|------|----------|
| 普通敌人 | 持续刷出；清剿拿达克特/尸骸掉落 |
| 宝箱 | 砸开获得资源或一次性奖励 |
| 神龛 | 短时增益或小抉择 |
| 精英 / 目标怪 | 高压高奖励；部分层需处理才开传送门 |
| 传送门 | 离开本层的出口；找到并进入 |

拖太久会被威胁淹没；过早进门则错失构筑资源——决策核心。

## 层间

进入传送门后：

1. 结算本层拾取入账。
2. 打开层间商店（达克特侧 + 尸骸遗物侧，见对应 Feature）。
3. 玩家整理军队后确认「下一层」。

## 胜负（定案，可测）

| 结果 | 充分必要条件 |
|------|----------------|
| 胜利 | 终局 Boss 生命归零 |
| 失败 | **指挥官生命归零** |

补充规则（与 [combat_threat_revive.md](./combat_threat_revive.md) 一致）：

- 场上有存活随从：打到指挥官的伤害**全额分摊到随从**（不吃随从防御；首版无溢出回指挥官）。
- 场上无存活随从（无论复活队列是否为空）：伤害打指挥官本体；生命归零 → 失败。队列仍可继续复活；复活出第一名后恢复分摊。
- 传送门**默认始终可进**（不因未清精英锁门）。精英/目标怪是高收益选项，不是进门门禁；若某层主题需要「清目标才开门」，该层在内容表里单独标注，默认层不采用。
- 「威胁过高打不过」不是另设失败类型：打不过就会灭队/指挥官归零，走同一失败条件。

失败与胜利均进入结算，并按 [meta_progress.md](./meta_progress.md) 发放永久进度。

## 玩家操作摘要

| 阶段 | 操作 |
|------|------|
| 层内 | 移动指挥官；集合随从；释放短时强化（及角色主动） |
| 层间 | 购买/刷新/出售/合兵；购买遗物；确认进层 |
| 结算 | 确认回主菜单 / 再开一局 |

## 对象骨架（功能）

```text
一局状态
  → 当前楼层序号、地城类型
  → 胜负状态（进行中 / 胜 / 负）
  → 本局随机种子

楼层
  → 布局、刷怪点、交互物、传送门
  → 威胁时钟（见战斗 Feature）

指挥官
  → 位置、角色能力、是否可战
```

## 验收要点（完全 · 随 Phase）

- 能开一局、进至少一层、经传送门到层间、再进下一层（Phase A/B）。
- 终局胜利与失败结算可复现（Phase F）。
- 相关 `*_test_runner.gd` 覆盖楼层切换与胜负状态机；GUI 证据覆盖层内 HUD 与层间商店可读（达 L4 时）。
