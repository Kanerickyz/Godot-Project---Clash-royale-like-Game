# Feature：打击感 / 商店刷新 / 刷怪加速 / Boss 视野 / 闲逛

> 状态：设计已定稿，玩法实现完成（轻量验收，效果待用户自验）  

> 验收方式：**轻量**（`bash tools/run_light_verify.sh`；效果用户自验）

## 玩家可观察变化

1. **撞飞有抛物线 Tween + Boss 硬冲**：受害者沿击退方向做可辨时长（约 0.4s）的水平插值，精灵本地 y 做假高度抛物线（先上后下），可带轻微旋转并落地回正；伤害+硬直在撞击开始结算一次。Boss 冲撞路程用速度硬冲（`velocity` + `move_and_slide`），不对路程做缓动 Tween；蓄力用醒目预警/后仰，起步用短促 scale punch 再全速冲。
2. **商店不永久售罄**：可花费金币**刷新货架**；当前页角色全部买光时**自动刷新**。刷新后重新上架可购角色（可与原池相同或重roll，本切片：从商店候选池重roll 三槽）。
3. **刷怪越来越快**：随比赛进行时间，续刷间隔逐渐缩短（有下限），压迫感上升。
4. **Boss 视野 = 冲撞最远距离**：Boss 索敌/压境感知距离与 `charge_distance` 一致（可随行为配置）。
5. **敌人未发现目标时偶尔移动**：无仇恨目标时短距闲逛/踱步，而不是永久站桩。

## 规则要点

### 商店
- 购买仍扣角色标价；买走的槽标记为空/已购，但**不再是终局售罄**。
- **手动刷新**：按钮花费可配置金币，重roll 当前货架。
- **自动刷新**：当前页所有槽都已购买后，立即（或关闭再开前）自动刷新，不额外扣刷新费（本切片：自动刷新免费）。
- 候选池：沿用现有商店三角色定义，刷新时从池中随机/洗牌取满槽。

### 刷怪加速
- 有效间隔 = lerp(初始区间, 最短间隔, 进度)；进度由开局经过时间 / 可配置参考时长得出，clamp 0–1。
- 具体点数进 `world_spawn.tres`。

### Boss / 敌人 AI
- Boss：`aggro_range` 设为行为配置的 `charge_distance`（生成时与配置变更时保持一致）。
- 普通敌人：无目标时启动闲逛计时，到期朝随机近距方向走一小段再停。

## 非目标（一句）

不改 Boss 冲撞主循环公式；不做多层商店 UI；不新增货币。
