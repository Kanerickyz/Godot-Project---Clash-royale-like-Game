# Feature：程序化地图与刷怪/箱

> 状态：已实现（轻量加载可自检；效果用户自验）  

> 验收方式：**轻量**（`bash tools/run_light_verify.sh`；效果用户自验）  
> 依赖：[GAME_VISION.md](../GAME_VISION.md)、[squad_roam_prototype.md](./squad_roam_prototype.md)

## 玩家可观察变化

1. 镜头比原先略远，同屏可见范围更大。
2. 地图明显更大。
3. 开局敌人与宝箱位置**随机**（不落在固定坐标表）。
4. 随时间推进，会再刷出新的敌人与宝箱。
5. 关卡呈现类 roguelike 的**分区布局**（房间式空地 + 走廊感连通），每局布局可不同。
6. 地表为两种颜色草地瓦片棋盘格交替拼接（overworld 图集中的黄绿 / 橄榄绿）。

## 布局规则（本切片）

- **一张大开放图**，用程序生成若干「房间」矩形空地，以走廊连通；地面用两种草地瓦片棋盘格铺满。
- **安全区**：商店与开局队长附近为安全/低威胁，开局不刷敌；Boss 落在远离开局的房间。
- **刷怪点**：在非安全房间内随机取点；与实体保持最小间距；尽量不重叠障碍。
- **不做**：多层楼、小地图 UI、种子选关界面、可编辑地牢瓦片管线；当前不做土路/河流/道具瓦片层。

## 刷怪 / 刷箱

| 时机 | 规则 |
| --- | --- |
| 开局 | 随机刷若干敌人与若干宝箱（数量可配置） |
| 随时间 | 每隔一段可配置时间，再刷一批敌人和/或宝箱；可设场上存活上限，满则跳过或少刷 |
| Boss | 仍唯一；开局生成在远房间，不随时间重复刷 |

商店：仍一处；放在开局附近或指定安全房间。

## 镜头与地图尺度（功能）

- 地图边长相对原 `1600×1200` **明显增大**（具体点数可配置）。
- 相机 zoom 相对原 `1.85` **略拉远**（数值变小即看得更远）；仍服务竖屏可读。

## 非目标（一句）

无多层地牢、无完整瓦片编辑器管线、不改招募/Boss 冲撞机制本身。
