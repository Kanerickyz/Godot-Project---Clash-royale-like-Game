## 本文要写什么

第一货币**达克特**（Ducats）、层间商店招兵/刷新/出售、利息、招募品级、以及**三合一**升阶规则与军队类型上限。

## 本文不写什么

尸骸与遗物店细则、誓约加成数值、具体标价与刷新费（数值填空）、星级倍增合成（已否决，见下）。

## 合兵定案（防回归）

**3 个同种同品阶 → 下一品阶 1 个。**  
新兵 ×3 → 老兵；老兵 ×3 → 冠军。  
不采用 2/4/8/16 星倍增合成表（与参照实战冲突）。

## 达克特（Ducats）

| 用途 | 说明 |
|------|------|
| 购买单位 | 层间货架上的兵 |
| 刷新货架 | 花费达克特刷新候选 |
| 利息 | 层间未花光的达克特可产生利息（公式留给数值；功能上「有利息」） |
| 获取 | 层内击杀/箱/精英掉落，指挥官拾取入账 |

## 军队约束

- 同时最多约 **6 种**不同单位类型（种类上限；同种多份与合兵后仍算一种类型）。
- 可出售单位换回部分达克特（比例留给数值）。
- 冠军携带关键词，供誓约系统读取。

## 层间商店（招兵侧）

1. 展示有限货架槽；每槽一个候选单位与标价。
2. **购买**：扣达克特，单位加入军队（受种类上限约束）。
3. **刷新**：扣刷新费，重抽货架。
4. **招募等级**：可花费达克特提升商店招募等级，提高高稀有单位出现率（费用曲线留给数值）。**归属 Phase B**（与招兵店同切片；无等级则稀有度权重固定基线）。
5. **出售 / 整理**：卖兵、查看合兵预览。
6. **合兵默认自动**：获得第 3 个同种同品阶时立即合成，并给出可读反馈（光效/飘字/日志择一）；不另开手动确认弹窗。

货架内容受已解锁兵池与招募等级影响。

## 品阶

| 品阶 | 含义 |
|------|------|
| 新兵 | 商店购入的基础形态 |
| 老兵 | 3 新兵合成；更强 |
| 冠军 | 3 老兵合成；更强并**显式带关键词** |

同种单位共享兵种定义；品阶改变属性倍率与外观提示（可用同一贴图 + 边框/光晕区分，技术美术另定）。

## 对象骨架（功能）

```text
钱包
  → 达克特余额
  → 利息结算钩子（**每次进入层间时**按当前余额结算一次）

商店状态
  → 货架槽（单位定义、标价、是否锁定）
  → 招募等级
  → 刷新费用

军队
  → 单位实例列表
  → 类型种数 ≤ 上限
  → 合兵检测（同种同品阶计数）
```

- 利息在**每次进入层间时**可测（Phase B）。
- 三合一升到老兵与冠军，冠军带出关键词（Phase C）。
- runner 覆盖购买失败（钱不够/种类满）、合兵边界；L4 商店 UI 可读。
