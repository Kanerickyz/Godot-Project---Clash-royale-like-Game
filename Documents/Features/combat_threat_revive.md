# Feature：层内战斗、威胁与复活队列

## 本文要写什么

层内实时自动战斗、威胁随时间上涨、指挥官受伤规则、阵亡单位复活队列、玩家可发指令。

## 本文不写什么

商店与合兵、誓约具体加成表、遗物词条、地图生成算法细节、具体 DPS/血量。

## 战斗模型

- **玩家**：只控指挥官移动（虚拟摇杆 / WASD）。
- **随从**：自动跟随/索敌/攻击；不逐个点选微操。
- **指令**（全军或合同约定范围）：
  - **集合**：随从快速收拢到指挥官附近。
  - **怒意（短时强化）**：短时提升战斗属性（冷却可配置）。
  - 角色主动：随指挥官解锁（如投掷、领域），首版可只留接口。

表现与逻辑分离；胜负与伤害结算不依赖帧率。

## 威胁上涨

- 层内存在**威胁时钟**（沙漏意象）：随时间推进，敌人强度/刷怪压力上升。
- 非固定「第 N 波表」；而是**持续刷怪 + 威胁倍率**。
- HUD 需可读展示当前威胁档或趋势（UI 细则另开切片时可补）。

威胁逼迫玩家在搜刮与进门之间做选择。

## 指挥官受伤

- 场上有存活随从时：打到指挥官的伤害**分摊到全体存活随从**；**不吃随从防御**；首版**无溢出回指挥官**。
- 分摊发生时：**拉长复活队列剩余时间**（惩罚拖战与站桩）。
- 场上无存活随从时：伤害打指挥官本体生命；归零即整局失败（见胜负定案）。
- 复活队列中的单位**不参与**分摊，仍按序复活。

## 复活队列

- 随从阵亡后进入**复活队列**，按死亡顺序排队。
- HUD（常见左下）显示队列与倒计时。
- 复活位置：指挥官附近或安全点（可配置）。
- 「蜂群」向构筑可依赖死触发与复活节奏；规则上允许频繁阵亡—复活，而非永久减员（除非整队崩溃导致失败）。

```text
复活队列
  → 条目：单位引用、剩余时间、顺序
  → 受指挥官受伤、遗物、誓约修正
```

## 层内交互物（战斗侧）

| 物 | 行为要点 |
|----|----------|
| 敌人 | 自动交战；死亡掉落达克特/尸骸等到地，指挥官拾取 |
| 宝箱 | 有生命或交互；摧毁/开启给奖励 |
| 神龛 | 交互后获得短时效果或小选择 |
| 精英 | 更高威胁与奖励；可读标识 |
| 传送门 | 靠近确认进层 |

## 对象骨架（功能）

```text
单位（友军 / 敌军）
  → 生命、攻击（伤害、间隔、射程）、移动、阵营
  → 品阶（新兵 / 老兵 / 冠军）
  → 关键词（冠军可见；见誓约）
  → 复活相关修正

威胁系统
  → 时钟、当前倍率、刷怪权重修正

指挥官
  → 移动、指令冷却、受伤分摊入口
```
