# Feature：召唤冲撞 Boss

> 状态：已实现（轻量加载通过；效果用户自验）  
> 验收方式：**轻量**（`bash tools/run_light_verify.sh`；效果用户自验）  
> 依赖：[GAME_VISION.md](../GAME_VISION.md)、[squad_roam_prototype.md](./squad_roam_prototype.md)

## 遭遇边界

在现有「小队游走」同图 Boss 上，把 Boss 从「大号杂兵」升级为**机制差异化**单位：更大占地、直线冲撞（撞飞+扣血+短硬直）、召唤小兵辅压、独立行为循环。

**操作沿用愿景**：玩家操控队长（摇杆/WASD）；队友自动跟打。脑暴中的「纯全自动 + 仅焦点」不取代队长控制（愿景已有优先）。

## 玩家可观察变化

- Boss 体积/碰撞明显大于普通敌人。
- Boss 会蓄力并给出路径预警，然后直线冲撞；卷入的我方与小兵被撞飞、扣血，并短硬直。
- Boss 会召唤小兵骚扰；小兵可被冲撞碾掉。
- Boss 在压境 / 蓄力冲撞 / 召唤 / 硬直之间切换，不再只会追击普攻。

## 行为循环

1. **压境踱步**：缓慢逼近或侧移靠近队伍；可用较短距离普攻（保留），但不作为主威胁。
2. **蓄力冲撞**：出现可读路径预警 → 直线高速冲击。
3. **召唤小兵**：在 Boss 附近放出敌方小兵（辅压）。
4. **短暂硬直**：冲撞或召唤结束后可打窗口，再回压境。

压境后在冲撞与召唤间交替（可配置）；每次冲撞/召唤后进入硬直。

## 冲撞规则

1. 蓄力须有路径预警与反应窗口。
2. 冲撞路径宽度大于普通单位；可一次卷入多名单位。
3. 路径上每个卷入的**我方单位与敌方小兵**：先撞飞，再扣血；同一次冲撞对同一目标最多结算一次。
4. 被撞单位进入短硬直（期间不能有效移动/攻击），结束后恢复。
5. 冲撞结束 Boss 进入短暂硬直。

## 小兵

- 职能：骚扰占手，非主威胁。
- 可被冲撞碾掉。
- 行为近似普通敌方近战；使用独立或复用杂兵定义，数量与节奏可配置。

## 对象属性骨架（功能）

```text
Boss（相对杂兵）
  → 生命 / 攻击 / 移动（压境移速可低于冲撞速度）
  → 占地（更大碰撞半径）
  → 冲撞（预警时长、路径宽度、冲撞速度、伤害、撞飞距离、目标硬直、Boss 硬直）
  → 召唤（每次数量、冷却/交替节奏）

被撞单位
  → 短硬直（失控时长）
```

具体点数见 `resources/`（由数值填写）。

## 胜负

沿用小队原型：击败 Boss 胜；队长死亡败。

## 非目标（一句）

本切片不做 Boss 回血/加攻态；不改招募/经济主循环；不要求最终美术。
