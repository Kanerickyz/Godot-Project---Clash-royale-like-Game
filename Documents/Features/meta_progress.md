# Feature：永久成长边界

> 状态：To-Be 定稿（未实现）  
> 验收方式：完全  
> 相邻：[run_floors_and_victory.md](./run_floors_and_victory.md)、[delivery_phases.md](./delivery_phases.md)

## 本文要写什么

局外永久进度：技能点、解锁（角色/天赋/地城/兵池）、与一局结算的交接。只定边界与对象，不定技能树长表。

## 本文不写什么

完整技能树节点、付费内购、赛季战令、联网排行榜。

## 边界

| 局内 | 局外 |
|------|------|
| 达克特、尸骸、军队、遗物、本局誓约状态 | 技能点余额、已解锁角色/天赋/地城类型/兵种 |
| 一局结束全部清空（除结算转化） | 跨局保留 |

- **胜利与失败都发技能点**（量可不同，数值定）。
- 技能点用于角色技能树或全局解锁；不同角色可偏向不同关键词构筑（如起始角色偏先锋/护甲）。
- 挑战式解锁：完成指定地城挑战 → 解锁内容（Phase G 落地最小集）。

## 开局消费局外进度

- 已解锁角色可选。
- 已解锁开局天赋可选（若该 Phase 启用天赋）。
- 未解锁内容在 UI 上可见锁定原因（达 L3+ 时）。

## 对象骨架（功能）

```text
账号进度（本地存档即可）
  → 技能点
  → 解锁集合（角色、天赋、地城、兵种）
  → 各角色技能树已购节点

结算单
  → 本局结果、发放技能点、新解锁提示
```

## 验收要点（完全 · 随 Phase）

- 结算发点、存档、下局读取（Phase G）。
- 至少一条解锁链可玩（如通关第 N 层解锁某兵或地城）。
- runner 覆盖存档读写与「未解锁不可选」；无需联网。
