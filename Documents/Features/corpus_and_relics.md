# Feature：尸骸货币与遗物商店

> 状态：To-Be 定稿（未实现）  
> 验收方式：完全  
> 相邻：[economy_shop_merge.md](./economy_shop_merge.md)、[combat_threat_revive.md](./combat_threat_revive.md)

## 本文要写什么

第二货币**尸骸**（Corpus）、层间遗物商店、遗物对军队/指挥官/复活的功能修正类型。

## 本文不写什么

完整遗物花名册与数值、达克特招兵规则、具体掉率。

## 尸骸（Corpus）

| 项 | 说明 |
|----|------|
| 获取 | 层内击杀、精英、部分宝箱/神龛；与达克特可同源分账或分池掉落（实现取清晰一种） |
| 用途 | 购买/刷新**遗物**（战利品），不用于买兵 |
| 展示 | 与达克特分列；层间遗物商使用尸骸标价 |

## 遗物商店（层间）

- 与招兵货架同层间出现，或分栏同一界面。
- 可花费尸骸购买遗物；可花费尸骸刷新遗物货架。
- 遗物有持有上限或槽位（可配置）；可替换（规则留给实现：卖旧买新或覆盖确认）。

## 遗物效果类型（功能大类）

```text
遗物
  → 防御类（护甲、减伤）
  → 进攻类（攻击、攻速、暴击）
  → 复活类（缩短队列时间、死亡触发）
  → 经济类（达克特/利息/拾取）
  → 誓约互动类（强化某关键词或计数规则）
  → 存活条件类（全队存活时双加成等）
```

具体词条在 Content 或资源中随 Phase E 填入一小撮可玩集合即可，不要求上线即完整图鉴。

## 验收要点（完全 · 随 Phase）

- 尸骸入账与遗物购买/刷新走通（Phase E）。
- 至少一类遗物在战斗中可观测生效（如复活缩短）。
- runner 覆盖买不起/槽满；L4 遗物栏可读。
