# 游戏愿景

> 状态：已落盘；主循环由 `scenes/main/main.tscn` 实现（轻量验收通过，效果待用户自验）  
> 验收方式：轻量（`bash tools/run_light_verify.sh`；效果由用户自验）

## 一句话

控队长在城池节点间行军，进城招人、低买高卖一种货；路上遭遇则打自动小队战；赚取金币财富，队长阵亡（或无法再战）则结算本局分数。

## 主循环

1. 开局队长带空货、少量金币，位于一座城池节点（世界层）。
2. 进城打开安全菜单：花钱招人、按本城标价买卖同一种货，或离开回世界层。
3. 在城与城之间的路线上移动；可直达邻城；途中按概率触发遭遇。
4. 遭遇进入战斗层：只控队长，队友自动跟打；打赢可掉金币（队长踩到入账），回到世界层并保留队伍与货物。
5. 队长死亡或队伍无法再战 → 本局结束；**分数只算身上金币**（持货作废，不折算进分）。
6. 无通关 Boss 终局；可随时再开一局比分。

## 已拍板操作与边界

- **控制**：世界层在城/路线上移动；战斗层只控队长（底部居中虚拟摇杆 / WASD）；队友自动跟随、自动攻击。
- **空间**：双层——世界层（城池节点 + 路线）与战斗层（复用小队自动战）；首版至少 2 座城、1 种货。
- **招募**：城内菜单花钱招人（标价可见）；打赢遭遇不招募。
- **跑商**：每城对该货有可见买/卖价；买扣金币、卖加金币；可持货跨城。
- **结算**：持货在失败时作废；分数 = 结算时金币。
- **不做（本愿景范围）**：攻城、势力、俘虏、多货种供应链、背包容量、战斗中抢货、永久跨局成长、同图 Boss 通关。
